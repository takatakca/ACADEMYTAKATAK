# TAKATAK University — GitHub source-to-curriculum inventory
Date: 2026-11-15. Source: authenticated GitHub connector repository metadata and selected README documentation. This is a **first-pass curricular inventory**, not complete code/CI/deployment/security verification across all repositories.

## Coverage and protection
GitHub linked-account inventory: **87 repositories accessible** under `takatakca`, **74 public** and **13 private** at inspection. Private repository names/details deliberately omitted from this public Academy repository. Some repository READMEs are absent/empty; treat content as unverified until exact file and branch review.
- Do not read from or copy private production data, user messages, real restaurant orders, legal files, medical records, access tokens, customer credentials, staff data or unpublished commercial secrets into public or AI-tutor course material.
- A public README may describe a feature that is not deployed. Teach it as hypothetical until the exact product run and data rights are confirmed.
- Approval needed: subject matter expert, source provenance and licence, correct product screenshots/demo data, academic accessibility and release reviewer. Store user/private learning records only in scoped Academy DB.
- A client site/logo is not automatically licensed as University course media. Use owned/authorized demo materials, independently reviewed.

## Not automatically curriculum-approved
- Sensitive projects touching employment, legal services, finance, youth/family, adult platforms or regulated subjects require separate expert reviews; no private or vulnerable-person records.
- The 13 private repository sources are **internal analysis only** and cannot become teaching content or learner retrieval without explicit approved rights and redaction.
- One repository may be used across multiple schools, but original course lessons must point to an approved snapshot/version, not blindly ingest its entire Git history.
- Empty/unavailable READMEs require later deeper source review; do not infer deployment or technical functionality.

## OBNL and enterprise offerings (proposed)
- OBNL digital literacy training, nonprofit digital transformation, job readiness, funding/reporting workflows, volunteer and nonprofit administration; no unsupported claims of accreditation or legal compliance.
- Group scholarships/sponsored licenses only through signed TAKATAK agreements, V1 billing and independently verified master organization identity.
- Academy may track signed seat assignments but cannot grant premium course entitlement from a seat row.
- Staff/teacher review remains separate from organization's training coordinator access; no employer access to private workbook or personal AI chats by default.
